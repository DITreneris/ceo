Chapter 1Daily · Ritual

Daily CEO ritual (about 10 minutes)

When: start of the business day, before meetings. Do: write yesterday’s numbers, then run Daily Fast (page 5). Use Daily Deep (page 6) only if something broke or you must choose what to delay.

Owner
CEO or COO — one person collects the numbers.
Walk away with
Three priorities for today, each with an owner and a time.
Done
You can name today’s top 3 without opening another chat.

Good input vs bad input

Bad — skip this

Revenue was fine. Had some meetings. Expenses normal.

Good — paste this

Revenue $2,340 (+8% vs prior day). 3 new leads (Acme, Beta Co). Expenses $1,200 (payroll run). Server incident 2h — root cause pending.

If your input looks like the left column, do not run the prompt yet. Add dollars, names, and one dated event first.

Chapter 1Daily · Fast

Daily prompt — Fast

When: weekday morning, yesterday’s numbers in hand, 5 minutes. Use Daily Deep (page 6) if you must choose what to delay. You should get: 3 priorities, names, times.

Daily · Fast5 min
ROLE: Operations analyst advising a CEO/COO (US B2B SaaS or services).

CONTEXT: Company [SaaS / services] · Goal [this week] · Constraints [cash, headcount]

FACTS (yesterday only):
- Revenue: [$] · Leads: [count + names] · Expenses: [$] · Events: [one-line list]

TASK: Name exactly 3 priorities for today from yesterday’s actuals.

RULES: Do not invent numbers. Flag gaps before recommending. One-sentence why per priority.

OUTPUT:
1. Summary (max 3 lines)
2. Table: priority | why | action | owner | deadline | risk
3. CEO decision required: [one line]

QUALITY: If FACTS lack dollars or events, ask up to 5 questions first — then stop.

Chapter 1Daily · Deep

Daily prompt — Deep

When: an incident, a slipped deal, or a capacity clash. Use Daily Fast (page 5) if you only need today’s top 3. Done when you have one yes/no for the CEO and one item you will delay.

Daily · Deep15 min
ROLE: Operations analyst advising a CEO/COO (US B2B SaaS or services).

CONTEXT: Company [SaaS / services] · Goal [this week] · Constraints [cash, capacity, customer commitments]

FACTS (yesterday + this-week effect):
- Revenue: [$] · Leads: [count] · Expenses: [$]
- Events with dates: [list] · Pipeline note: [one line or “none”]

TASK: What changed, what to delay this week, and one yes/no the CEO must answer today.

RULES: Facts only in “what changed.” Do not invent numbers. Max 3 priorities. Label estimates.

OUTPUT:
1. What changed (facts only, max 5 lines)
2. Table: priority | action | owner | deadline | what we delay
3. CEO decision required: [Yes / No — one choice]

QUALITY: If revenue, expenses, or events are missing, ask up to 5 questions first.

Chapter 2Weekly · Fast

Weekly prompt — Fast

When: Monday, numbers ready, no major trade-off. Use Weekly Deep (page 10) if you must stop or delay a project. You should get a 1–3 project rank and 3 actions.

Weekly · Fast10 min
ROLE: Weekly operations analyst advising a CEO/COO.

CONTEXT: Company [SaaS / services] · Horizon: this week · Constraints [runway months, hiring freeze]

FACTS:
- Revenue / costs / cash: [$] / [$] / [$]
- Projects: [name, % complete, status]
- Pipeline: [deals, stages, dates]

TASK: Rank projects 1–3 and name the top 3 actions this week. No delay list needed.

RULES: Do not invent cash or deal values. Flag missing pipeline. Max 3 priorities.

OUTPUT:
1. Summary (max 3 lines)
2. Project rank 1–3 (one-line why)
3. Table: priority | action | owner | deadline | risk
4. CEO decision required: [one line]

QUALITY: If projects or pipeline are vague, ask up to 5 questions first.

Chapter 3Friday

CEO reflection (weekly)

When: Friday, last 10 minutes. Do: paste facts only — not feelings. You are done when you have one measurable behavior for next week.

ROLE: Strategic coach for a CEO/COO.

FACTS: Goal [this week] · Went well [facts] · Went poorly [facts] · Metrics [numbers] · Assumptions [list]

TASK: Fact-based Friday reflection. Recommend one behavior change for next week.

RULES: Separate facts from interpretation. Do not invent events. One change only — specific and measurable.

OUTPUT:
1. Facts vs interpretation (2-column table)
2. Assumption to challenge (max 1)
3. Behavior change | how I will measure it next Friday
4. CEO decision required: keep or drop that change

QUALITY: If facts are vague, ask up to 5 questions first.

Sample output

Facts: Revenue $12,500 · demo slipped 2 days. Interpretation to drop: “pipeline is fine.” Change: CEO joins every demo over $20K · measure: count next Friday.

Monday numbers5 rules

Economic discipline (top 5 rules)

When: you are ranking weekly priorities (pages 9–10). Apply the first matching trigger. You are done when this week’s table names cash and obeys any trigger that fired.

  1. Cash first. If the weekly FACTS omit cash balance, stop and add it before you accept the AI table.
  2. Runway trigger. If runway is under 6 months, one of this week’s 3 priorities must be a cash action (collect, cut, or delay spend).
  3. Cost spike. If weekly cost is more than 10% above last week, CFO labels it one-time vs recurring before you lock priorities.
  4. Pipeline risk. If more than half of pipeline sits in one deal, name a contingency owner this week.
  5. No vanity priorities. If a row is “brand” or “awareness” with no revenue or retention metric, delete it and re-run.
If you need a full runway scenario or ROI row, that is a finance job — not a daily prompt. Use your CFO pack or a strategy review, not pages 5–6.

This week4 habits

Techniques that work for CEOs

When: you have run at least one Daily Fast. Do these four this week. You are done when the Friday reflection uses the same thread as Monday.

1

One thread per week

Monday: start one chat. Each morning, paste updated numbers into that thread — do not open a new one.

2

Edit before you share

Before the ops meeting, delete any row without an owner. The table you show is yours, not the model’s.

3

Log within 24 hours

After Monday (page 11), add one row to the decision log (page 14) the same day.

4

Friday in the same thread

Run reflection (page 13) in that weekly chat so the model sees the week’s facts.

Do not paste customer PII, cap tables, unreleased financials, or privileged legal material.

JudgmentMistakes

Common mistakes (and fixes)

When: the ritual feels busy but decisions repeat. These are judgment errors — prompt failures live on page 16.

  • You accept the table as the decision. Mark facts vs assumptions (loop step 3), then you sign. The model does not adjourn the meeting.
  • You paste weekly totals into Daily Fast. Horizon blurs. Use page 5 for yesterday only; page 9 or 10 for the week.
  • You skip the log. Same debate returns next Monday. Write one row on page 14 before you leave the room.
  • You shop tools instead of Day 1. If you have not run Daily Fast with real numbers, go to page 2 — do not add another app.
You are done with this page when you can name which of the four you did last week — and which page fixes it.

Quick Reference2 minutes

CEO quick picks

When you have 2 minutes — not 15. Copy, paste, get a decision. Full prompts stay on pages 5–10.

Monday morning · 2 min

When: No time for Daily Deep, need priorities now.

Yesterday: Revenue $[X], Leads [N], Expenses $[X].
Give me 3 priorities for today with one owner each.
Flag if runway or a deal is at risk. Max 5 lines.

→ Output: 3 priorities · owners · one risk flag

Cash red flag · 2 min

When: Runway concern or unexpected cost spike.

Cash balance: $[X]. Runway: [N] months.
If runway < 6 months, name ONE cash action this week.
Owner and deadline required.

→ Output: one action · owner · deadline

Priority cap · 2 min

When: Team has more than 5 AI-generated bullets.

Here are my current priorities: [list].
Force exactly 3. Drop or merge the rest.
State the one-line reason for each kept priority.

→ Output: 3 priorities · clear rationale

Friday reflection · 2 min

When: End of week, 5 minutes before close.

This week: [2-3 facts — what went well, what missed].
Give me: 3 facts vs 1 assumption I'm making.
Recommend one behavior change for next week.

→ Output: facts · assumption · one behavior change

Ops or strategy · 2 min

When: Unsure if this is today’s ops call or a longer commitment.

Issue: [one sentence]. Urgency: [high/medium].
Is this a daily ops decision or a strategic commitment?
If strategic, name the frame: runway / growth lever / risk.

→ Output: ops or strategic label · next step · which page or review to use
